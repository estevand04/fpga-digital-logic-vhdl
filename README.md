# FPGA Digital Logic Design (VHDL)

## Overview
This repository contains digital logic projects built using VHDL and tested on a Nexys FPGA board.

## Projects Included
- D-Latch
- Multiplexer (MUX)
- Flip-Flop
- Adder circuits
- Comparator and 7-segment display

## Tools
Vivado, Nexys FPGA Board

## What I Learned
- VHDL design and simulation
- Digital logic fundamentals
- FPGA workflow and debugging
